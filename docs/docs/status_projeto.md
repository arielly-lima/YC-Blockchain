# Status do projeto

## Resumo

O projeto está em fase de **definição e construção do MVP para o Youth Challenge Blockchain 2026**. A arquitetura e a proposta estão consolidadas; as integrações técnicas e a validação com usuários ainda precisam ser demonstradas.

## Estado por componente

| Componente | Estado | Evidência necessária |
| --- | --- | --- |
| documentação | 🟢 em construção | revisão da equipe e especialistas |
| experiência infantil | 🟡 definida conceitualmente | protótipo navegável e teste de usabilidade |
| painel profissional | 🟡 escopo definido | fluxo funcional |
| ASR base | 🟡 tecnologia candidata | benchmark em português |
| adaptador pessoal | 🔴 a implementar | comparação antes/depois |
| pipeline de dados | 🔴 a implementar | dataset versionado de demonstração |
| Psyche Network | 🔴 experimental | run técnico documentado |
| blockchain | 🟡 registros definidos | contrato ou protótipo funcional |
| consentimento | 🟡 modelo conceitual | fluxo acessível e validação jurídica |
| modelo financeiro | 🟡 hipótese | entrevistas com instituições |

## Escopo da demonstração

1. Mostrar uma falha de reconhecimento.
2. Executar uma missão curta de voz.
3. Validar a intenção comunicativa.
4. Criar uma versão autorizada do dataset.
5. Adaptar ou simular a adaptação do modelo.
6. Comparar resultados técnicos.
7. Exibir proveniência e consentimento na blockchain.

## Riscos abertos

- proteção de voz infantil;
- integração entre Psyche e modelos de áudio;
- qualidade e quantidade de dados;
- revogação após treinamento;
- feedback clínico indevido;
- custo computacional;
- excesso de escopo para o hackathon.

## Definição de pronto para o MVP

O MVP está pronto quando o fluxo ponta a ponta pode ser demonstrado com dados seguros, métricas explícitas, limites comunicados e nenhuma alegação clínica não validada.
